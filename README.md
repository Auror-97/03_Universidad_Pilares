# **SISTEMA WEB UNIVERSITARIO**

Proyecto colaborativo de desarrollo web enfocado en el diseño y desarrollo de interfaces para un sistema de gestión universitaria, utilizando HTML y CSS.

## **Descripción**

El proyecto contempla diferentes interfaces orientadas a alumnos, profesores y personal administrativo, con el objetivo de organizar y presentar información académica y de usuarios.

## **Mi participación**

Participé en el diseño y desarrollo de diferentes interfaces del sistema, principalmente en las secciones de Inicio y Administración, además de colaborar en el diseño visual de otros módulos.
En este repositorio se incluye como muestra la interfaz de **Perfil del Alumno**, desarrollada por mí como parte del proyecto.

## **Elementos desarrollados**

- Estructuración de la interfaz mediante HTML.
- Estilos personalizados con CSS.
- Implementación de layouts utilizando CSS Grid y Flexbox.
- Menú lateral desplegable.
- Organización de información mediante pestañas.
- Diseño y distribución de los elementos de la interfaz.

## **Tecnologías utilizadas**

- HTML5
- CSS3
- CSS Grid
- Flexbox

## **Estado del proyecto**

Proyecto colaborativo en desarrollo.

> **Nota:** El código incluido en este repositorio corresponde a la interfaz desarrollada por mí dentro del proyecto colaborativo.
